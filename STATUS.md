# STATUS

**Documented state:** odv tools 0.0.6 (2026-11-11): extra passes in *Post-production output* (mist, AO, light groups, reflection, refraction, emission, environment, albedo, custom AOVs) as hidden PSD layers, with presets (#22); the PSD is written again in Blender 5.0 and 5.1. 0.0.5 (2026-11-11): new tool *Post-production output*: per camera a final-look 16-bit PNG beauty, the Material ID file and a layered 16-bit PSD, with render, shadow and photo as separate layers in photo-match scenes (#20, #21). 0.0.4 (2026-11-11): new tool *Material ID*, one fixed flat colour per material in the AOV `odv_matid` (#19). 0.0.3 (2026-11-11, tagged but never published; its changes were first released in 0.0.4): optional clean-up on update in the Archicad FBX Updater, *Merge by distance* and *Smooth by angle* (#10). 0.0.2 (2026-10-30): panel improvements of the Archicad FBX Updater (#5), released to test updates from the extension repository (#4). 0.0.1 was the first release: the Blender tools packaged as one extension (#3).

**Review status.** The code was written with AI assistance: the first updater script with ChatGPT (2026-04), the Archicad FBX Updater add-on v2.0.0 in an AI-assisted session that was not recorded (2026-08-26).
Neither has been reviewed line by line.
Treat it as working tools for our own projects, not reviewed software.

Legend: **Tested** = a recorded check with named data · **In use** = used in our projects, no recorded check · **Implemented** = in the code, not exercised on record · **Proposed** = discussed, not built.
