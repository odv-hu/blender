# blender

Tools for work inside Blender itself, such as UV mapping and scene clean-up.

| Tool | What it does |
| --- | --- |
| [Material ID](material_id/) | Gives every material a fixed flat colour in its own render pass (AOV), for masks in post-production. |
| [Post-production output](post_output/) | Per camera, a final-look 16-bit beauty, the material ID file and both as one layered PSD. |
